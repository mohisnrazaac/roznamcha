## 2. Step 1 Carryover: `X-Robots-Tag` Verification & Fix

### Issue Analysis
While `<meta name="robots" content="noindex, follow">` was correctly rendered in SSR HTML, search engine crawlers require and prioritize the `X-Robots-Tag: noindex, follow` HTTP response header.

### Fix Applied
In `app/Http/Middleware/SecurityHeaders.php`:
```php
// Check explicit noindex route patterns
if ($request->is(
    'features',
    'features/*',
    'survival-report',
    'templates',
    'templates/*',
    'kharcha-map',
    'ration-brain',
    'electricity-bill-calculator-*',
    'petrol-price-*',
    'ration-rate-*'
)) {
    return 'noindex, follow';
}
```
Additionally, an inspection of rendered HTML contents was added as a fallback to catch any response where `<meta name="robots" content="noindex` was generated by Inertia/Blade.

## 3. Task 2: Electricity Bill Estimator Tariff & Calculation Accuracy

### Tariff Adjustments (NEPRA S.R.O. 279(I)/2026 Compliance)
1. **GST Rate:** Updated from `0.17` (17%) to `0.18` (18%) in `config/public_tools.php` and `ElectricityBillEstimator.jsx`.
2. **Billing Methodology:**
   - **Unprotected Residential Consumers:** Calculated non-telescopically. The entirety of units consumed is multiplied by the base tariff of that specific unit bracket.
     - $1\text{--}100$ units: Rs 22.43/unit
     - $101\text{--}200$ units: Rs 28.52/unit
     - $201\text{--}300$ units: Rs 32.78/unit
     - $301\text{--}400$ units: Rs 37.78/unit
     - $401\text{--}500$ units: Rs 40.06/unit
     - $501\text{--}600$ units: Rs 41.44/unit
     - $601\text{--}700$ units: Rs 42.72/unit
     - Above $700$ units: Rs 47.37/unit
   - **Protected Residential Consumers ($\le 200$ units):** Calculated with the one-previous-slab benefit:
     - First 100 units billed at Rs 10.54/unit.
     - Units 101 to 200 billed at Rs 13.01/unit.
     - Lifeline brackets (up to 50 @ Rs 3.95, $51\text{--}100$ @ Rs 7.74).
3. **Taxes, Surcharges & Adjustments:**
   - **Financing Cost (FC) Surcharge:** Rs 0.43/unit (protected) / Rs 3.23/unit (unprotected).
   - **Fuel Price Adjustment (FPA / FCA):** Default Rs 3.00/unit (configurable).
   - **Quarterly Tariff Adjustment (QTA):** Default Rs 2.50/unit (configurable).
   - **Fixed Charges:** Rs 400 ($1\text{--}300$ units) / Rs 600 ($301+$ units) per kW sanctioned load.
   - **Electricity Duty (ED):** 1.5% of energy base cost.
   - **PTV License Fee:** Rs 35 flat fee.
   - **Advance Income Tax (Sec 235):** 7.5% applicable for non-filers when the gross electricity bill reaches or exceeds Rs 25,000.
4. **Editorial Accuracy:** Updated editorial tag to `"Last verified & updated: November 2026"`.
